# ClassQ&A
An Anonymous Question Submission platform to improve classroom engagement between student and instructor

## 🚀 Project Roadmap & Features

**Phase 1-3: Core Infrastructure (Completed)**
- [x] Relational Database Schema (Users, Classes, Questions, Upvotes)
- [x] Backend Express Server & REST API
- [x] Custom Profanity & Moderation Filter
- [x] Unified User Authentication (Bcrypt Password Hashing & JWT Sessions)
- [x] Global CSS Variable Architecture (Light/Dark Mode)
- [x] Multi-Page Navigation & Role-Based Dashboards

**Phase 4: The Classroom Engine (Up Next)**
- [ ] **Class Creation:** Instructors generate a 6-character `join_code`.
- [ ] **Student Enrollment:** Students join classes securely via code.
- [ ] **Session Management:** Instructors open/close active Q&A feeds to restrict questions to specific timeframes.

**Phase 5: UI & UX Polish**
- [ ] Animated Network Loading Bar
- [ ] Skeleton Loaders for empty feed states
- [ ] Toast Notifications (Success/Error popups)
- [ ] Modern Empty State Illustrations
- [ ] CSS Page Transitions

**Phase 6: Advanced Q&A Features**
- [ ] Feed Sorting Toggle (Most Upvoted vs. Most Recent)
- [ ] Click-to-Filter Tags
- [ ] "Answering Live" Glowing Badge for active questions
- [ ] Pinned Questions (Instructor feature)
- [ ] Real-Time WebSockets (Socket.io)
- [ ] Password Reset Flow

**Phase 7: Instructor Power Tools**
- [ ] CSV Data Export (Download session analytics)
- [ ] Hidden Profanity Dashboard to monitor flagged users
